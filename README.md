# Takudzwa Wilson Muzavazi — GIS Portfolio

A responsive, single-page professional portfolio built for GitHub Pages with semantic HTML, modern CSS, and a small amount of vanilla JavaScript. It uses no framework, package manager, build step, or third-party front-end dependency.

## What is included

- CV-based profile, project narratives, work history, education, skills, leadership, and contact information
- Original map and contour-line visuals built with inline SVG and CSS
- Responsive navigation and mobile menu
- Accessible focus states, skip navigation, reduced-motion support, and semantic section structure
- Scroll reveals, animated impact figures, active navigation, and copy-email interaction
- Downloadable PDF curriculum vitae
- Custom 404 page and SVG favicon
- `.nojekyll` file for direct GitHub Pages compatibility

## Publish on GitHub Pages

1. Create a GitHub repository and add the contents of this folder to its default branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the default branch and the root folder, then save.

GitHub will publish the site after its Pages workflow completes. All links are relative, so the portfolio works at both a user-site address and a project-site address.

## Content updates

- Edit portfolio copy and section order in `index.html`.
- Adjust colors, spacing, and responsive behavior in `assets/css/styles.css`.
- Replace the PDF in `assets/files/` while keeping the same filename to preserve every CV link.
